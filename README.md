# Mohamed Sayed Abdulrazek — Portfolio

Personal portfolio of Mohamed Sayed Abdulrazek, .NET backend developer and Computer Science student at Benha University.

Live at **[mohamedsayedabdelrazek.github.io](https://mohamedsayedabdelrazek.github.io/)**

- Plain HTML, CSS and JavaScript, served by GitHub Pages. No build step.
- Icons are Font Awesome Free SVGs, self-hosted as CSS masks in `icons.css` (regenerate with `python tools/build_icons.py <path-to-fontawesome-svgs>`).
- The Learning Platform diagram is generated by `python tools/build_erd.py`.
